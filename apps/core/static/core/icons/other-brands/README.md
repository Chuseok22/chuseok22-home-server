# Other Brands

Simple Icons에 없는 브랜드 아이콘을 개별적으로 벤더링해 보관하는 디렉터리다.

## 필수 형식(중요)

이 디렉터리의 모든 SVG는 Simple Icons와 동일한 형식이어야 한다 — **`viewBox="0 0 24 24"`,
`<path d="...">` 엘리먼트가 정확히 1개**, 그 외 `<g>`/`<circle>`/다중 `<path>`/고정 `fill` 색상
없음. `brand_icon` 템플릿 태그(`apps/site/templatetags/icon_tags.py`)는 이 형식이 아닌 파일을
만나면 안전을 위해 **아이콘을 아예 렌더링하지 않는다**(깨진 모양으로 렌더링하는 대신 빈 문자열을
반환). devicon 등 원본 SVG는 대부분 이 형식이 아니므로(다른 viewBox, 다중 path, 브랜드 색상 등)
그대로 복사하면 안 되고, 24×24 단일 path로 직접 정규화해야 한다.

## 추가 절차

1. Simple Icons(https://simpleicons.org)에서 슬러그를 먼저 확인한다 — 있으면 여기가 아니라
   `../simple-icons/`를 그대로 쓴다(재벤더링 불필요).
2. 정말 없는 브랜드라면, 반드시 사용자에게 먼저 확인한다(`.claude/rules/21-icon-usage.md` 원칙 2).
3. 공식 소스(devicon 등)에서 SVG 원본을 구한 뒤, 위 "필수 형식"에 맞게 24×24 단일 path로
   정규화해서 `{slug}.svg` 파일명으로 이 디렉터리에 추가한다. 외부 CDN URL을 코드나 데이터에
   직접 저장하지 않는다(원칙 3).
4. **정규화할 수 없다면(적절한 단일 path 버전을 찾을 수 없다면) 벤더링을 강행하지 말고 사용자에게
   다시 확인한다** — 형식에 안 맞는 파일을 넣으면 `brand_icon`이 그 아이콘을 조용히 그리지 않는
   것으로 끝나므로, 데이터 저장(`Skill.icon_slug` 등)이 막히지는 않지만 화면에서는 빈 자리로
   남는다.
5. `Skill.icon_slug` 등에는 이 파일명(확장자 제외)을 슬러그로 저장한다.
